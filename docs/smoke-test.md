# dsh-hitchfin 真实账号冒烟清单

这份清单用于在发布前验证**真实 DSH + 真实厂商账号**下的行为。自动化测试（`npm test`）覆盖协议、路由、生命周期与边界，但不能替你做厂商账号的真实登录、图片识别和长会话压缩。

当前冒烟基线：`main` 上的最新 commit（安装包由 `npm pack` 生成）。

## 0. 准备

1. 使用**测试 profile**（例如单独的 web profile），不要把测试包直接覆盖日常 desktop profile；如果必须覆盖，先备份 `~/.dsh/profiles/<name>`。
2. 安装本轮 tarball：

   ```sh
   dsh plugin --profile <test-profile> add ./dsh-hitchfin-0.5.1.tgz
   ```

   通过 DSH 插件页面安装时，选择本地 tarball / 本地目录。
3. 确认版本：DSH 插件页或日志中应显示 `dsh-hitchfin` 已加载。
4. 冒烟期间不要升级渠道包版本，保持 `package-lock.json` 不变。

## 8. 回滚

- 代码回滚：`git revert <commit>` 或切回上一个 release 的 tarball。
- profile 回滚：恢复备份的 `~/.dsh/profiles/<name>`，或在插件页卸载后重装旧包。
- 不要通过手工改 desktop profile 的依赖来“修”问题；优先用插件页/测试 profile。

## 9. 通过标准

- 第 1.4、1.5、1.6 项必须通过（图片、压缩、切模型）。
- 第 2.3 项必须通过（free-only 不出现付费模型）。
- 第 3.2 项必须通过（取消登录释放 loopback）。
- 第 5.1/5.2 项必须通过（无重复路由、无遗留 worker）。
- 安全项无明文 token 泄漏。
